# Simple E-Commerce Art Platform
A responsive e-commerce art platform where users can browse artwork, view product details, add items to their cart, and simulate an online shopping experience. The project is built using HTML, CSS, and JavaScript, with a focus on creating an intuitive and visually appealing user interface.

## Features
* Browse a collection of artwork
* View product details
* Add items to the shopping cart
* Remove items from the cart
* Responsive and user-friendly interface
* Dynamic cart functionality using JavaScript

## Technologies Used
* HTML5
* CSS3
* JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.

## Project Purpose
This project was developed to practice front-end web development concepts, including responsive design, DOM manipulation, and JavaScript-based interactivity by building a functional e-commerce website.
